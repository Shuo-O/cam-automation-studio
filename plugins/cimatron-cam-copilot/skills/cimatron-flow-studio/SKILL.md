# Cimatron Flow Studio

Cimatron is delivered here as a static Journaling parser with dry-run evidence
only. There is no
Cimatron FlowGraph capability manifest, Flow import path, live host bridge,
command-task transport, or semantic editing contract.

Review a supplied static evidence report without inventing Flow nodes or mapping
opaque calls to production actions. Explain the unavailable capability and keep
all source spans and unknown fields intact. If a request asks for Cimatron Flow
import, return an explicit unavailable-capability result.

Never create or execute a PreviewPlan, replay a Journal, attach to Cimatron,
generate source, emit NC/G-code, or claim simulation, collision, or shop approval
from static evidence alone. Human review remains a separate required gate.
