# 客户验收手册

## 离线验收

- 在干净 Python 3.10+ 环境运行 `python scripts\customer_self_check.py --json`，结果必须为 `status=passed`。
- 启动工作台并完成：导入快照 → 案例检索 → 建议 → 四道证据门禁 → 导出。
- 确认导出包含 `schema_version=1`、快照/案例/建议哈希和 `dry_run=true`。
- 执行一次备份和恢复；默认覆盖保护应阻止写入已有文件，恢复目录中的文件哈希应一致。
- 检查 ZIP 中不存在 `build/`、`.git/`、测试/研究中间文件、密钥候选或客户数据。
- 用 `delivery/examples/` 模板完成一次 fixture 演示，并确认页面标出 fixture 来源，未将演示快照当作客户数据。

## 现场验收（本机未代替完成）

客户需记录目标 NX/PowerMill/Cimatron 版本、真实零件和刀具库、只读快照对应性、仿真记录、碰撞检查记录和现场批准人。NX/PowerMill 的真实只读导出与连接在本交付中未现场验证；Cimatron 仅为静态实验解析能力，不得与 NX/PowerMill 制造快照支持混淆。没有这些记录时，只能宣称离线系统验收通过，不能宣称宿主生产验证通过。
